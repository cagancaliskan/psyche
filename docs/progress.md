# Progress

This page is the public record of Psyche's research plan: the phases that started or finished, the
gates that were decided, the dates that changed and the hash commitments made. A new row appears
when the plan records an event. The tables are written from
[`tools/research_plan.json`](../tools/research_plan.json), the only source of the plan's dates, and
nothing in them is typed by hand.

## Log

Newest first. One row for each phase started or finished, each gate decided, each change recorded in
the plan's change log and each hash commitment. The plan marks a phase as started or finished, so a
date that has passed does not add a row by itself.

A decided gate shows only the date it was decided and what follows: the line continues to the next
phase, extends, or stops. Its verdict, its evidence and the reasoning behind it stay private, under
the [disclosure policy](research/disclosure-policy.md), and a decision lifts no rule of the
[claims discipline](research/claims-and-scope.md). Every gate, with its question and its fallback,
is on the [decision gates](research/gates.md) page.

## Commitments

A hash commitment shows that a file was fixed before the work it judges, without showing the file:
the table holds the date, a one-line subject and the file's SHA-256 hash, and the file itself is
revealed at the time shown. How a commitment is made and checked is set out in the
[disclosure policy](research/disclosure-policy.md#pre-registration-without-disclosure).
