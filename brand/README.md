# Psyche brand

The mark is a P built in stages: one stem and three nested bowls hung from a shared top edge. Each
bowl is kept whole inside the next, the innermost lit in the signal colour, and the outer bowl stays
open at the stem so a new stage can always wrap what exists. It is how the project works: each stage
built test-first and kept.

## Files

| File | Use |
|---|---|
| `psyche-wordmark-dark.svg` | Primary wordmark on dark backgrounds |
| `psyche-wordmark-light.svg` | Primary wordmark on light backgrounds |
| `psyche-wordmark-mono.svg` | One colour (`currentColor`): print, embossing, single-colour contexts |
| `psyche-mark-dark.svg`, `psyche-mark-light.svg` | The P alone, where the name is already present |
| `psyche-mark-mono.svg` | The P in one colour (`currentColor`) |
| `psyche-icon.svg` | App and avatar icon: the simplified P on the dark canvas |
| `favicon.svg` | Browser favicon (same drawing as the icon) |
| `psyche-social.png` | Social preview, 1200 x 630 |

The wordmark letters are outlined from Unbounded (weight 200, tracking 0.08 em), so no file needs the
font installed. The P is drawn on a 24-unit grid with a 1.68-unit stroke.

## Colour

| Role | Dark canvas | Light canvas |
|---|---|---|
| Canvas | `#05070d` | `#f5f7fb` |
| Ink (stem, outer bowl, letters) | `#f4f6fb` | `#0a0d14` |
| Structure (middle bowl) | `#8aa2ff` | `#2f4fd6` |
| Signal (inner bowl) | `#5ef0c4` | `#087a5c` |

The signal colour belongs to the inner bowl only. Never recolour the bowls, swap their order, or add
a fourth.

## Use

- **Clear space:** keep at least the height of the inner bowl free on every side of the wordmark, and
  half the mark's width around the mark.
- **Minimum size:** wordmark 18 px tall on screen; the full mark 24 px; below that, use the icon
  drawing (two bowls) as the favicon does.
- **Do not** stretch, rotate, outline, add shadows or glows, place the colour wordmark on busy
  imagery, or set the letters in another typeface.
- On photographs or colour fields, use the one-colour version.
